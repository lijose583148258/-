# 🚀 翻译通 · 零成本编译 APK 完整指南

本指南面向没有编程基础的用户，一步步教你把代码变成可以安装在手机上的 APK 文件。
全程免费，不需要服务器，不需要安装任何开发工具，只需要一个浏览器。

---

## 第一步：注册 GitHub 账号（已有账号跳过）

打开 https://github.com，点击右上角 Sign Up，注册一个免费账号。
邮箱验证完成后即可使用。

---

## 第二步：创建代码仓库（Repository）

1. 登录 GitHub 后，点击右上角 **「+」→「New repository」**
2. Repository name（仓库名）填写：`fanyi-tong`
3. 选择 **Public（公开）** ← 免费账号必须选公开才能使用 Actions
4. 不要勾选任何初始化选项
5. 点击 **「Create repository」**

---

## 第三步：上传代码文件

你下载到的 ZIP 压缩包解压后，是一个叫 `fanyi_app` 的文件夹。

**方法一（推荐，最简单）：直接网页上传**

1. 进入刚创建的仓库页面，点击 **「uploading an existing file」**
2. 把 `fanyi_app` 文件夹里的**所有文件和文件夹**拖入上传区域
   - 注意：要上传文件夹内容，不是压缩包本身
   - 文件较多时，浏览器可能需要 1-2 分钟处理
3. 在页面底部填写 Commit message（随便写，如"初始版本"）
4. 点击 **「Commit changes」**

**方法二（进阶）：使用 Git 命令**

```bash
cd fanyi_app
git init
git remote add origin https://github.com/你的用户名/fanyi-tong.git
git add .
git commit -m "初始版本"
git push -u origin main
```

---

## 第四步：等待自动编译（约 5-8 分钟）

上传代码后，GitHub Actions 会**自动触发编译流程**。

查看编译进度：
1. 进入仓库页面，点击顶部 **「Actions」** 标签
2. 看到「翻译通 - 自动编译 Android APK」正在运行（黄色圆圈 = 进行中）
3. 点进去可以看到每个步骤的实时日志
4. 全部完成后变成绿色 ✅

编译成功后，编译日志页面底部会出现 **「Artifacts」** 区域。

---

## 第五步：下载 APK

1. 在绿色 ✅ 的 Actions 运行记录里，滚动到底部
2. 找到 **「翻译通-release-apk」**，点击下载
3. 解压下载到的 ZIP 文件，里面就是 `app-release.apk`

---

## 第六步：安装到手机

**华为/荣耀：**
1. 把 APK 文件传到手机（微信、QQ、数据线均可）
2. 打开文件管理器，找到 APK 文件，点击安装
3. 首次安装会弹出「允许安装未知来源应用」→ 点击「设置」→ 开启 → 返回继续安装

**小米：**
1. 设置 → 隐私保护 → 安装未知应用 → 选择你使用的文件管理器 → 允许
2. 然后点击 APK 安装即可

**OPPO/vivo：**
1. 直接点击 APK 文件
2. 弹出"安全提示"→ 点击「继续安装」

## 常见问题

**Q：编译失败，报红色 ❌ 怎么办？**
点进失败的步骤，查看红色报错信息。常见原因是文件上传不完整（比如遗漏了 assets 文件夹），
重新上传缺失的文件，然后在 Actions 页面点击 「Re-run all jobs」重试即可。

**Q：APK 安装后打开是英文界面？**
手机语言设置为中文即可，App 会自动跟随系统语言显示中文。

**Q：翻译功能提示「词库未收录」？**
这说明你输入的词汇本地词库里没有，此时 App 会自动联网调用 MyMemory 翻译。
如果也没有网络，则显示原文。后续词库会持续扩充。

**Q：语音功能无法使用？**
进入手机「设置 → 应用 → 翻译通 → 权限」，确认麦克风权限已开启。
越南语语音识别还需要手机安装越南语语音包（设置 → 语言与输入法 → 语音识别）。

## 更新 App 的方法

以后每次修改代码，只需：
1. 在 GitHub 网页上修改对应文件（或重新上传）
2. Commit 提交后，Actions 自动重新编译
3. 下载新的 APK，安装覆盖旧版本即可（数据会保留）
